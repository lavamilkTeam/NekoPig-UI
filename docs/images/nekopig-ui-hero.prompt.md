## 提示词

Use case: ui-mockup
Asset type: README hero banner for the existing open-source QML component library NekoPigUI
Primary request: A beautiful polished 3D product render of one UI showcase panel viewed at an oblique angle, with many interface components and visibly floating layered cards and panels

Composition: Wide landscape 16:9, high resolution, entire main panel and floating layers visible with generous margins. A single large thin rounded rectangular desktop application panel is suspended above a seamless light gray studio ground, viewed from a three-quarter overhead angle, approximately 35 degrees, with convincing consistent perspective. The app plane runs diagonally across the frame. Several individual rounded UI cards float at different small heights above the main application panel; their offset soft gray shadows clearly communicate depth. All cards parallel to the main plane and organized in an intentional grid, readable and spacious, avoid chaotic pile or exploded machinery

Design language: faithfully inspired by a minimalist Qt Quick library: near white background #FFFFFF, soft off-white card surfaces #F7F7F7, subtle light gray selection fills #E8E8E8, charcoal text #303030, saturated blue #0866D8 accent. Borderless cards, softly rounded corners, restrained subtle thin gray input outlines. Very thin physical edges, UI sheets rather than thick plastic blocks, soft ambient occlusion, no glass transparency

Main panel header: three small red amber green window control dots, exact brand text "NekoPigUI" in clean sans serif. A segmented navigation strip beneath, three short labels "Controls", "Navigation", "Overlays", one pale gray selected tab
Floating UI content: a settings card with Name text field reading "NekoPig", a toggle switch, and a charcoal rounded button labeled "Apply"; a card with three text radio choices, one selected with a small blue dot and pale gray selection; a horizontal capsule slider, blue active track continuous under a crisp white circular thumb with a fine gray outline, warm-gray remaining track, no tick dots; a thin blue rounded progress bar and a small circular loader; a minimal spinbox "-  24  +"; a floating expanded dropdown panel showing three short text options with one light-gray selected row; a text-only scrolling list card with one gray rounded selected row; a small floating dialog with a text field and two action buttons; a compact tooltip. Feature roughly 7 to 9 well-composed grouped cards, enough interface detail to communicate a full UI kit, not a dense analytics dashboard

Lighting: soft broad studio light from upper left, luminous neutral environment, beautiful shallow but unmistakable layered elevation, delicate soft gray shadows falling right and below each card, crisp anti-aliased UI edges, all interface surfaces in focus, no depth of field blur
Text: Only brand "NekoPigUI" and short purposeful control labels, accurate clean readable sans serif, no marketing tagline or paragraph
Avoid: device frame, laptop, keyboard, hands, people, charts, illustrations, decorative icons, neon lighting, purple gradients, exaggerated thick extrusions, heavy borders, harsh dark shadows, excessive tilt, illegible pseudo-text, watermarks
Output: One finished landscape README hero image
